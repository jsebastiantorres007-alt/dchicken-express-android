# D’Chicken Express — compilación de prueba Android

Repositorio de automatización para crear un **APK de prueba** de D’Chicken Express Control.

La interfaz web se obtiene durante la compilación desde el sitio oficial de producción:
https://dchicken-express-control.vercel.app

**Privacidad:** este repositorio no incluye movimientos financieros, usuarios, claves privadas ni el código fuente de la aplicación. Las claves publicables de la app web no son claves administrativas. Los datos permanecen protegidos por las políticas de Supabase.

Para obtener el APK: visita **Actions**, selecciona **Compilar DChicken Android APK**, abre la ejecución más reciente y descarga el artefacto **DChicken-Android-APK**. El artefacto contiene el archivo **app-debug.apk**.

El APK es una versión de **prueba**, no una aplicación aprobada por Google Play. Debe verificarse en un teléfono Android antes de usarlo con movimientos reales.

Recomendación: cambia la visibilidad a **Private** en Settings → General → Danger Zone → Change repository visibility antes de añadir más código.
